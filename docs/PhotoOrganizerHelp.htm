Canup Photo Organizer Help

Welcome

Canup Photo Organizer helps you review, compare, rename, move, copy, convert, rotate, rate, and organize image files using saved sessions.

What Is a Session?

A session is a saved workspace for a photo-organizing job. A session remembers the folders and display settings you want to use so you can return to the same work later.

  • One or more source folders
  • Any destination folders used by Copy and Move
  • Which right-click actions are shown
  • Thumbnail size, sort order, and side-pane size
  • Display options such as showing file names, showing actions in the info panel, and highlighting date differences

Getting Started

  • Start the application. If no sessions exist yet, the session editor opens automatically.
  • Enter a session name.
  • Add one or more source folders.
  • Optionally select destination folders for copy and move actions.
  • Choose which right-click actions should be visible.
  • Save the session.

Supported Files

The application can load these source types:

  • JPG / JPEG
  • PNG
  • GIF
  • TIFF / TIF
  • HEIC / HEIF
  • PDF

Main Window

  • The image grid is on the left.
  • The information pane is on the right.
  • The divider between them can be resized.
  • The File menu contains session commands.
  • The Undo menu opens the undo history window.
  • The Help menu opens this embedded help file.

Adjusting Thumbnail Size

  • Move the mouse over an edge of a thumbnail cell in the image grid.
  • When the resize cursor appears, click and drag.
  • All thumbnail cells stay square and resize together.
  • The selected thumbnail size is saved with the session.

Selection and Navigation

  • Click to select one image.
  • Ctrl-click to add or remove an image from the selection.
  • Shift-click to select a range.
  • Double-click an image to open fullscreen view.
  • Arrow keys move a single selection.
  • Home and End jump to the first or last item.
  • Delete performs the same action as the Delete command.

View

The View action changes based on the number of selected items.

  • If one item is selected, View opens fullscreen.
  • If two items are selected, View opens compare mode.
  • The left image fills the left half of the screen.
  • The right image fills the right half of the screen.
  • Each image is scaled as large as possible within its half.
  • The filename, file size, and image dimensions are shown under each image.

Actions

The right-click menu shows only the actions enabled in the session settings.

  • VView: fullscreen for one selected item, compare for two selected items.
  • CCopy: copies selected files to a chosen destination folder.
  • MMove: moves selected files to a chosen destination folder.
  • DDate update: updates EXIF date taken and file modified time when supported.
  • RRename: edits a file name directly or applies a saved rename rule.
  • FConvert: creates a JPEG or PNG copy of the selected file.
  • AAutocrop: runs the built-in crop logic on supported image files.
  • ORotate: rotates the selected image files.
  • XDelete: removes selected files from the source and can use the Recycle Bin when available.
  • *Rating: clears or sets a Windows-style image rating for supported files.
  • EEdit: opens the selected file in the default external editor.

Renaming Rules

Rename rules are shared across sessions and can be managed from the File menu.

  • Each rule has a user-defined name.
  • Rules can add text to the start or end of a filename.
  • Rules can remove text, substitute text, or replace the full base filename.
  • Renaming changes only the filename without the extension.
  • Supported macros include %date%, %dateh%, %time%, %char##%, and %%.

Session Options

  • Show file name under thumbnail
  • Show actions in info panel
  • Highlight date differences
  • Recurse subdirectories of source
  • Sort order
  • Visible actions
Show actions in info panel adds the same action set that appears in the right-click menu to the information pane below the image details.
Highlight date differences shows a yellow border on non-selected images when the date in the file name, the file modified date, and the EXIF date taken do not all match by date.

Undo History

The Undo window shows recent changes for the current session.

  • Each entry includes the timestamp, action, and file details.
  • Undo Selected rolls back the selected changes and removes them from the log.
  • Clear Selected removes selected log entries without changing any files.

Stored Data

  • Session settings: C:\ProgramData\PhotoOrganizer\PhotoOrganizer.config
  • Change log: C:\ProgramData\PhotoOrganizer\PhotoOrganizer.changes.ndjson
  • Undo backup folder: C:\ProgramData\PhotoOrganizer\UndoBackups
  • Runtime requirement: .NET Framework 4.0 (CLR v4.0.30319)

Notes

  • JPEG and PNG ratings use the Windows rating property system.
  • GIF rating is not supported.
  • On some Windows systems, HEIC and HEIF support requires the HEIF image extensions and related codecs to be installed.
  • PDF files use a first-page preview.
